03 / Token 求值

同一组件只消费语义，不认识具体皮肤

A

语义 Token

组件使用 --color-surface、--color-text 和 --color-accent，而不是直接引用某个蓝色或紫色。

surface text accent
B

light-dark()

这个区域以普通声明作为回退，再由 light-dark() 根据元素最终采用的 color-scheme 选择颜色。

used scheme: light
C

局部主题作用域

局部容器覆盖语义 Token，同时设置自己的 color-scheme，无需修改全局状态。

04 / 渲染边界

并非所有像素都由同一套 CSS 自动更新

浏览器原生控件

color-scheme 告诉浏览器当前元素支持哪种模式，影响表单控件等用户代理绘制内容。

SVG：继承 currentColor

内联 SVG 可以通过继承和 CSS 类进入主题系统；外链图片则有不同边界。

Canvas：需要命令式重绘

Canvas 已经写入位图的像素不会因 CSS 变量变化自动改色，应用需要读取新 Token 并重新绘制。

render count: 0

05 / 检查点

在开发者工具中追踪这条链路

  1. 检查 <html> 上的 data-theme、data-scheme 和 data-skin。
  2. 查看卡片的 computed style，确认组件属性来自语义 Token。
  3. 切换系统偏好：仅在 requested mode 为 system 时，resolved scheme 才随之变化。
  4. 比较 SVG 与 Canvas：前者通过 CSS 继承自动更新，后者由 JavaScript 重绘。

该 Demo 验证浏览器内主题解析链路，不代表真实 SSR、跨源 iframe、移动设备或全部浏览器兼容性验收。
