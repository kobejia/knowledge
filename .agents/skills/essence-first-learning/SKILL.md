# 本质优先学习

## 目标

帮助读者在一段短阅读里建立正确的核心模型：先知道主题是什么、为何存在、解决什么问题，再理解支撑结论所需的最少机制、例子和边界。

本 skill 与 `personal-learning` 并列，不替换或修改它。`essence-first-learning` 负责短解释；`personal-learning` 继续负责有档位选择、审阅、分类、索引和可选实践的正式学习文档。

适用于用户想“先抓重点”“讲本质”“简单说清楚”“精炼一点”“通勤时读”或希望快速理解一个概念的请求。用户明确要求完整研究、系统梳理、专家级长文、知识库归档或完整实践时，不把短解释冒充成完整产物；按用户指定的范围与仓库流程处理。

## 阅读目标与篇幅

- 默认按 3–5 分钟阅读设计，中文正文通常约 800–1,400 字；英文正文通常控制在约 450–800 词。字数是编辑目标，不是牺牲准确性的硬上限。
- 开头先给答案。读者只看开头，也应知道核心本质、它解决的问题和关键背景。
- 只回答当前最重要的一个问题。主题过大时，选择能回答用户目标的核心切面，并用一句话交代范围；不要压缩成名词清单。
- 内容确实需要更多篇幅才能讲清时，优先删去次要支线、重复例子和旁枝历史；若仍超出篇幅，缩小到当前最重要的问题并说明范围。只有范围歧义会令回答失准时才询问，不以“要不要展开”作习惯性结尾。
- 用户明确要求长篇或全面内容时，服从当前请求，不强行套用短篇幅。

## 组织思路

写作前先在内部回答：读者究竟要理解什么？这个概念或系统为何出现？它处理什么约束？结论由什么机制或证据支撑？哪些边界会改变结论？

### 开头：几句话交代本质

用最短的自然表达覆盖以下信息；如某项确实不适用，不要硬凑：

- **本质**：它是什么，或最有用的心智模型是什么？
- **问题**：它要解决什么具体困难或回答什么问题？
- **背景**：是什么约束、需求或变化使它出现？背景应解释“为什么需要它”，不必补一段无关历史。

可用以下形式组织，但不要为凑齐标签写重复内容：

> X 的本质是……。它解决……；当……这一约束出现时，人们引入它，通过……起作用。

### 展开：从直觉走到机制

按读者需要选择自然结构，不要求每篇都使用同一组标题：

1. 先解释理解机制所必需的最少概念；每个术语首次出现时用短语说明。
2. 沿着因果或推理顺序说明关键过程，通常用 2–4 步讲清“输入/条件 → 发生什么 → 为什么 → 产生什么结果”。非技术主题则讲清观点、证据和推论之间的关系。
3. 只在能验证心智模型或展示关键差异时加入一个具体例子。例子从简，不写成教程或完整案例复盘。
4. 只保留会改变判断或适用范围的限制、代价、反例或不确定性。

结尾可用一句话重申读者值得带走的模型；若它只是重复开头，就直接结束。

## 准确与证据

- 精炼不等于武断。保留成立条件、必要因果环节和会改变结论的重要限制。
- 区分可核实事实、主流解释、作者推论和仍有争议的判断。不能确认时收窄结论或说明不确定性。
- 对版本、数据、规则、政策、争议性结论或其他易变化的信息，核对当前可靠材料；引用紧跟其支持的主张，只保留必要来源。
- 不为了“揭示本质”把复杂主题简化成单一口号、未经证明的因果关系或不准确类比。类比只作入口，并指出它在哪些地方不再适用。
- 如果核心问题有实质歧义，先用一个简短问题消歧；否则直接解释，不要求用户先选档位、目录或固定格式。

## 表达规则

- 直接说结论和因果关系。每句话只承担一个主要作用。
- 优先使用常用词、短句和主动表达；必要术语出现时立刻释义。
- 删除客套开场、重复结论、泛泛背景、无助于理解的历史沿革、同义改写、装饰性比喻、无关知识点和“总结一下”等占位段落。
- 不为了看起来系统而加入术语表、固定数量的优缺点、练习题、延伸阅读或章节；只有用户明确要求时才增加这些内容。
- 图表、列表和代码仅在比短段落更清楚时使用；不要把一段解释拆成过多碎片。

## 输出前检查

- 开头几句话是否明确说出本质、问题和必要背景？
- 是否解释了核心机制或推理，而不只是给出定义和结论？
- 是否按“先易后难”引入概念，没有把读者直接丢进术语？
- 每个例子、背景和限制是否帮助理解当前核心问题？
- 是否保留了重要前提、证据和不确定性？
- 删除任一句后，如果理解、推理、证据或适用边界都不受影响，就删掉它。
- 正文是否大致适合一次 3–5 分钟的碎片阅读？若超出，确认每一段都不可再删，并交代为何需要展开。

## 仓库产物

默认在当前对话中回答，不自动创建或改写文件。用户明确要求将结果保存为仓库学习文档时，保持本 skill 的精炼表达目标。若保存流程需要使用 `personal-learning` skill，先遵守仓库的 skill 授权规则；获授权后再按其配置、审阅、分类、索引和验证约定落盘，不得因篇幅目标绕过文档管理要求。
