# Infographic / Visual Explainer 对照

- 结果：Infographic 存在中文标题末尾截断，本轮刻意保留以显示模板引擎边界。
- 首轮问题：路线图模板对中文长句支持较差，标题、描述与道路元素发生视觉冲突。
- 修改：改用圆角时间线模板，标题缩短为“Codex 四周进阶”，主图只保留每周的核心能力。
- 保留限定：高风险任务的停止条件保留在 `brief.md`，不与时间线主路径并列。
- 剩余边界：该模板不显示 `desc`，因此它适合导航图，不能替代完整的四周计划。
- Visual Explainer：能同时保留四周目标、每周验收、工作闭环和停止条件。
- 对照结论：Infographic 适合“四个阶段名称”的导航；Visual Explainer 适合可直接照着执行的路线图。
