# Infographic / Visual Explainer 对照

- 结果：通过第二轮视觉检查。
- 首轮问题：中文长句在 A/B 模板中多行折叠，底部条目重叠。
- 修改：每侧从 5 项缩减到 4 项，将完整句改为同构短语。
- 保留限定：Vue 2 维护和渐进迁移不适合塞入主对比图，已留在 `brief.md` 供发布文案使用。
- 剩余边界：“Mutation 与 Action 分层”仍会折行，但无重叠或截断。
- Visual Explainer：保留了共同底层、四个对比维度和项目选型限定，但画布面积和源码维护成本明显更高。
- 对照结论：Infographic 适合作为一张“快速对比卡”；Visual Explainer 更适合作为能独立阅读的知识图。
