# 三、消息不是函数调用，而是内部协议与四、Manifest 是能力声明，也是威胁模型的核心模型、约束与取舍是什么？

## 三、消息不是函数调用，而是内部协议

- Chrome 提供一次性消息和长连接两类机制，连接范围覆盖 service worker、extension pages 与 content scripts。
- Chrome：Message passing 把下面这种代码散布在各处： 短期很快，长期会出现与后端 RPC 相同的问题：字段漂移、无版本、错误不可区分、请求与响应无法关联、权限检查遗漏。
- 更稳妥的协议至少包含： 协议设计的重点不是 TypeScript 类型本身，而是运行时约束： 1.

## 四、Manifest 是能力声明，也是威胁模型

- 插件能访问哪些浏览器能力和网站；
- 用户会看到哪些授权警告；
- 账号或插件被攻陷后的最大损害；
- Chrome Web Store 的审核与更新体验；
