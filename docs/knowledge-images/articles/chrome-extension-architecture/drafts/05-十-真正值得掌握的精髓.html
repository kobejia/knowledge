01

十、真正值得掌握的精髓

  • 操作系统式能力安全 ：manifest 和 permissions 类似 capability system，不应退化为全局管理员权限。
  • 分布式系统式状态管理 ：多个生命周期不一致的上下文通过消息协作，必须考虑重试、乱序、版本和恢复。
  • 事件溯源式后台设计 ：service worker 的短生命周期迫使业务从“常驻对象”转向“事件 + 持久状态”。
  • 声明式治理 ：平台把部分任意代码收敛成可审查、可限额、可优化的规则。
