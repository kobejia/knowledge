3. 核心变革：API 设计与逻辑封装

  • Vuex ：严格区分同步 ( mutations ) 和异步 ( actions )。修改状态必须 commit 。
  • 代价 ：代码割裂，简单的同步修改也需要定义 mutation 类型和函数。
  • Pinia ：移除 Mutations。 actions 可直接修改 state 。
  • 优势 ：利用 Vue 3 Proxy 的特性，任何位置的赋值都能被追踪。逻辑内聚，异步/同步操作可在同一函数完成。
