# 资源等 2 个主题：核心模型、约束与取舍

## 9. 资源

- OpenAI Developers：官方开发者入口，适合从总览理解 Codex 在 OpenAI 产品体系里的位置。
- Codex Use Cases：官方用例页，适合确认 Codex 适合处理哪些真实任务。
- Latest model guide：当你需要重新校准提示词或关注当前推荐模型时，先看这里。
- Personal Learn 配置：记录输出语言、学习目标、已有经验和熟悉领域。

## 10. 这篇指南的核心结论

- Codex 真正的价值，不是“替你想”，而是“帮你更快地把想法变成可验证的改动”。
- 对你这种已经有成熟前端经验的人来说，最值得追求的不是“让它多做一点”，而是“让它在正确的边界里做得又快又稳”。
- 如果你愿意，下一步最值得做的事情不是继续研究产品介绍，而是直接拿你当前知识库里的一个主题，按这篇指南跑一遍：先给 Codex 读仓库，再让它提计划，最后让它改一篇文档并给出验…
