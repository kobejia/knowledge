# Knowledge

一个由 AI 协助研究和撰写的深度知识库。

这里不追求教程数量和知识点覆盖率，而是围绕重要问题，理解其核心模型、演化过程、约束、取舍与边界。

## 内容原则

- 从关键问题出发，不从术语清单出发
- 优先解释设计动因和系统关系
- 区分事实、推论、主流观点与争议
- 关注反例、失败模式和适用边界
- 通过跨领域连接扩展认知视野
- 关键事实就近引用可靠来源
- 篇幅服从问题复杂度，不套固定模板
